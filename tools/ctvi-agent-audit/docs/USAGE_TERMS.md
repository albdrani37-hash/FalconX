## Product scope

CTVI Agent Audit is a local technical tool for supported normalized records. It checks record structure, declared provenance links and optional artifact-byte comparisons. It does not independently verify task success, truth, authorship, safety, scientific admissibility, legal admissibility, regulatory compliance or all CTVI research dimensions.

## Inputs and interpretation

Process only records and artifacts you have permission to use. Minimize and redact inputs before processing. Do not provide authentication secrets, government identifiers, payment-card information or protected health information to the plugin. The software does not automatically detect or remove every sensitive value.

Findings describe the supplied evidence. An absence of findings does not prove that a trace is complete, genuine or correct. Consider concurrency, export transformations and source limitations. Decisions requiring scientific, legal, medical, financial or security assurance need suitable evidence and review beyond this tool. See the [input format](INPUT_FORMAT.md) and [known limitations](KNOWN_ISSUES.md).
